Dream Journey Development Agency — মোবাইল স্টার্টার প্যাক

ফাইল:
- index.html: মোবাইল-ফ্রেন্ডলি ডেমো
- manifest.webmanifest: PWA পরিচিতি
- sw.js: সীমিত অফলাইন ক্যাশ
- README_BN.txt: এই নির্দেশিকা

ফোনে পরীক্ষা:
1. ZIP ফাইল Extract করুন।
2. index.html ফোনের ব্রাউজারে খুলুন। কিছু ব্রাউজারে সরাসরি file:// থেকে PWA ইনস্টল/অফলাইন সুবিধা কাজ নাও করতে পারে।
3. ডেমোতে সদস্য যোগ, সঞ্চয় জমা, লেজার, ডিফল্ট মাসিক সঞ্চয় এবং JSON ব্যাকআপ পরীক্ষা করুন।

APK করার বাস্তবসম্মত মোবাইল-অনলি পথ:
1. GitHub-এ বিনামূল্যে অ্যাকাউন্ট খুলুন/লগইন করুন।
2. নতুন public repository তৈরি করুন (যেমন dream-journey-demo)।
3. ZIP Extract করে index.html, manifest.webmanifest ও sw.js repository-তে আপলোড করুন।
4. Repository Settings → Pages → Deploy from branch → main / root নির্বাচন করুন।
5. GitHub Pages-এর প্রকাশিত HTTPS URL ফোনে খুলে পরীক্ষা করুন।
6. PWABuilder (https://www.pwabuilder.com/) খুলে প্রকাশিত URL দিন। Android package তৈরির অপশন ও প্রয়োজনীয় ধাপ অনুসরণ করুন। সাইটের বর্তমান নিয়ম/প্রয়োজনীয়তা অনুযায়ী অতিরিক্ত সেটআপ লাগতে পারে; APK তৈরি নিশ্চিত নয়।

গুরুত্বপূর্ণ সীমাবদ্ধতা ও নিরাপত্তা:
- এটি শুধু UI/লোকাল ডেমো; বাস্তব লগইন, অনলাইন ডেটাবেস, একাধিক ফোনে সিঙ্ক, সার্ভার ব্যাকআপ বা অনুমতি-নিয়ন্ত্রণ নেই।
- তথ্য ওই ব্রাউজারের localStorage-এ থাকে। ব্রাউজার ডেটা মুছে গেলে তথ্য হারাতে পারে।
- কোনো বাস্তব NID, পাসওয়ার্ড, ব্যাংক তথ্য বা সদস্যের আর্থিক তথ্য দেবেন না।
- বাস্তব সমিতির কাজে ব্যবহারের আগে নিরাপদ সার্ভার, অথেনটিকেশন, রোল-ভিত্তিক অনুমতি, audit log, backup/restore, এবং হিসাব যাচাই যোগ করতে হবে।
- এই স্টার্টার ফাইল নিজে থেকে Android APK নয়। APK প্যাকেজিংয়ের আগে HTTPS হোস্টিং প্রয়োজন হতে পারে।
